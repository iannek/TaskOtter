# タスク詳細のタブ・Markdownメモ案

[サンプルHTML](タスク詳細_タブとMarkdown案.html)をブラウザで開きます。ビルド・サーバー・外部ライブラリ・フォントのダウンロードは不要です。

- 基本情報：名前、ステータス、カテゴリ、Outcome、期間、締切、次の予定と作業内容、サブタスク。
- 資料・チャット：個別ボックスを追加・削除可能。タブに登録件数を表示。
- メモ：Markdownの編集／プレビューを切り替え。見出し、太字、斜体、箇条書き、チェックリスト、引用、リンク、表、コードの表示例を用意。

タブを切り替えても入力内容を保持し、保存／キャンセルは共通で下部に固定しています。Outcome行の「＋」からOutcomeを選択済みの新規Task画面を確認できます。メモタブのチェックリストはメモの表示であり、基本情報のサブタスクとは別です。

このHTMLは検討用で、保存は行いません。Markdownは外部ライブラリを使わない簡易レンダラーであり、Markdownの全仕様を網羅していません。HTMLは文字として表示し、リンクの移動先はhttp・https・mailtoのみ許可します。実装時には正式なMarkdown処理を検討します。

ブラウザでタブ切替、プレビューの各表示、タブ切替後の入力保持、HTML・不正リンクを実行しないこと、登録件数、Outcome選択済みの新規作成を確認しました。アプリ本体・依存関係・保存形式は変更していません。
