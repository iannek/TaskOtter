# 2026/10/06 追加要望のHTML案

対象：ドキュメント/確認結果・追加要望.mdの2026/10/06要望と、会話中の配置・見出し調整。アプリ本体や保存JSONは変更しない。

- Outcome名の横の＋を削除し、子Taskの末尾に「＋ 新しいタスクを追加」を配置。一覧・カード・ガントで共通。子が0件でも追加行を表示する。

- 親名は左端、子は字下げ。追加行の＋はチェック位置、文言はTask名の位置に揃える。青い縦線は表示しない。
- 一覧の「完了」列見出しを削除。「Outcome」と「Task」を分け、それぞれ親名・子名の開始位置に表示する。
- Task名の下に、資料・チャット・サブタスクの件数を常に表示。0件は「資料 0 · チャット 0 · サブタスク 0/0」。サブタスクは従来どおり完了数/総数。一覧・カード・ダッシュボード・ガント・カレンダーに表示する案。

HTML案では日付フィルターはブラウザ標準の日付入力。基準日はサンプルの2026-10-02。アプリ本体の共通日付ピッカー・API保存を置き換えるものではない。

## Outcome折りたたみの追加

一覧・カード・ガントの親名の左に▾／▸を配置。初期状態は展開。矢印を押すと子Taskと末尾の追加行を一緒に隠し、親名と期間は表示する。親名は詳細を開く操作を維持。Outcomeなし・子Taskが0件のOutcomeも開閉できる。ガントは名前と期間側を同時に折りたたむ。

開閉状態はサンプルのメモリ上で画面切替中も共有し、再読み込みで展開へ戻る。Enter／Space操作に対応したbuttonとaria-expandedを使用する。ダッシュボード・カレンダーの表示は折りたたみの影響を受けない。
